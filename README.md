# Funniest One-Line Out-of-Office Reply

An entry for [make.fun's "Funniest One-Line Out-of-Office Reply" bounty](https://make.fun/bounty/u-hamsyh-funniest-one-line-out-of-office-reply-5490c1c8): write ONE line — the funniest out-of-office email auto-reply. The program writes the line to `/output/entry.txt`.

The entry:

> I'm out of office; my auto-reply is currently the only one of us working.

## Run it

```bash
python3 main.py
```

This writes the one-line reply to `/output/entry.txt` (73 characters, one line, UTF-8).
